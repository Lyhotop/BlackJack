## Game Description  

Blackjack (21) is a classic card game where the goal is to have a hand value as close to 21 as possible without exceeding it.  
The game features:
- A **dealer** and a **player**.
- A dynamic deck that is shuffled each round.
- A system for calculating the score and determining the winner.
- **Betting** system with a balance to manage funds.
- **Animations** and **sounds** for enhanced user experience.
- A **menu** for navigation and settings.

## Features  
- Full implementation of Blackjack with a dealer and player interactions.
- Dynamic deck updates and score calculation.
- Animations and sound effects for card dealing and betting.
- Betting system and player balance tracking.
- Multiplayer (currently under development).
- Adaptive design for Android/iOS devices.

## How to Run the Project

### Prerequisites  
- [Node.js](https://nodejs.org/)  
- [Expo CLI](https://docs.expo.dev/get-started/installation/)  
- [Git](https://git-scm.com/)  
- Android/iOS emulator or physical device

### Installation  
```bash
git clone https://github.com/Lyhotop/BlackJack.git
cd BlackJack
npm install
```

### Start App
```bash
npx expo start
```
